Privacy Policy

Your file stays in your browser, with one exception you control.

Trace is a static site. It has no backend, no database and no analytics. This page states exactly when, and whether, a file leaves your machine.

The short version

With no SynthID key configured, nothing you open or paste leaves your browser. Not the file, not its bytes, not a summary of it.

With a SynthID key configured, the file you analyse is sent from your browser directly to Google's SynthID API at synthid.googleapis.com. That is the only network request Trace can make, and it happens only when you have deliberately set a key.

What Trace does with your file

When you drop, paste or pick a file, the browser reads it into memory and every check runs in this tab. Trace parses the bytes locally, uses canvas and video elements locally, and renders the result locally. None of that touches the network.

Trace does not store your file. It does not write it to disk, it does not keep a copy after you navigate away, and it does not send a hash, a thumbnail or a size anywhere.

The one exception: the SynthID check

Google's SynthID verification API is the only outbound network request in the codebase, and it is only called when you switch it on. The behaviour is:

  • No key set. Trace does not call the API at all. The panel reports the check as not configured, tells you that ordinary accounts cannot self-enable this API, and links you to Google's free public detector at synthid.com. Nothing leaves your browser.
  • Key set. Trace sends the raw file bytes as the request body to https://synthid.googleapis.com/upload/v1:verifyContent, with your key in the query string and the media content type in the header. Google's response is shown to you. Google's handling of that request is governed by Google's own terms and privacy policy, not by this one.

The key you enter is held in your browser's local storage so it survives a reload. It is sent only to Google, as the API requires. Trace has no server that could receive it.

Local storage

Trace uses your browser's local storage for one thing: to remember a SynthID API key and your mock mode setting if you choose to enter them. Nothing else is stored. You can clear both with the Clear key button in the settings panel, or by clearing site data in your browser.

No tracking, no third parties

There are no analytics, no advertising, no cookies for tracking, and no third-party scripts. Fonts are served from this repository rather than a font CDN, so loading a page makes no request to any third party. The only external link that leaves the site is the one to synthid.com, which opens only when you click it.

Changes

If the behaviour of this tool changes in a way that affects what leaves your browser, this page will state the new behaviour plainly. The current statement is simple: nothing leaves the browser unless you configure a SynthID key.
