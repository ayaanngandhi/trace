Client-side provenance inspection

Read what a file says about where it came from.

Trace reports what authoritative sources say about a file: a signed C2PA content credential, the SynthID watermark read through Google's API, and the provenance metadata the file carries. Every check runs in this tab. Your file is not uploaded, and there is no server to upload it to.

Inspect a file

Images up to 8 MB. Audio and video up to 100 MB. The file never leaves this machine.

  • Pick a file

SynthID check

Configure a SynthID API key

With a key set, the file you analyse is sent from this browser straight to Google's SynthID API. With no key, nothing leaves this browser. The key is stored only in this browser's local storage.

The API must be enabled for the project that owns the key. Enable it on the SynthID API page, then create a key under Credentials.

Trace is a static site. There is no backend, no build step and no tracking. Your file stays in this browser except when you deliberately configure a SynthID key.
