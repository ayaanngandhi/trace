Client-side provenance inspection

Read what a file says about where it came from.

Trace looks for signed content credentials, generator metadata, invisible watermark structure and forensic traces. Everything runs in this tab. Your file is not uploaded, and there is no server to upload it to.

Inspect a file

Images and video, up to browser limits. The file never leaves this machine.

  • Pick a file

    Use the button above to open a normal file chooser.

SynthID check

Configure a SynthID API key

Only do this if your Google Cloud account has SynthID access. With a key set, the file you analyse is sent from this browser directly to Google's SynthID API. With no key, nothing leaves this browser.

Trace is a static site. There is no backend, no build step and no tracking. Your file stays in this browser except when you deliberately configure a SynthID key.
