What Trace is

Trace is a client-side inspector that reports provenance signals found in a media file. It reads signed C2PA content credentials, calls Google's SynthID verification API when you configure a key, and parses embedded EXIF, XMP and IPTC metadata. It summarises what it found as a verdict, and it runs entirely in your browser.

What the results mean

A result is a report of signals, not a statement of fact about the media. It is not a determination that an image, audio file or video is real, fake, human made or machine made. Absence of a signal never means the content is authentic, and this tool does not describe any file as authentic, safe, verified real or not AI.

Each check has limits, and the SynthID service accounts for most of them: resolution, frame rate, quality and tampering can all cause it to abstain rather than decide. An abstention is the absence of a verdict. A check that did not run, because no key was configured, is reported as not configured and not as a clean result.

Signatures and authority

Trace reads a C2PA manifest with the official C2PA library and validates its signature. A manifest reported as found is one whose signature validated and whose signer was identifiable, but that only establishes who signed the claim. It does not establish that the claim is true, and it does not establish that the content is truthful or unedited since it was signed.

The other authoritative result Trace displays is a live response from Google's SynthID API, which runs only when you configure a key whose project has the API enabled.
